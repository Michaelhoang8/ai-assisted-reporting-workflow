# Optional evidence-grounded reporting prompt

Given reports/evidence_packet.json, produce JSON with dataset_id, claims, interpretations and recommendations. Claims must each contain metric_id, the exact typed value and unit from the packet. Interpretations/recommendations are arrays of objects with text and evidence_ids. Cite only metrics also present in claims. Put no numerals, percent signs or currency signs in qualitative prose: the verified renderer inserts quantitative statements. Do not infer costs, cash receipts, return matching, marketing channels or causality. Discuss deduplication sensitivity, missing customers and incomplete final-month coverage. The source is observed historical UCI data, not a synthetic business case.

Review the draft, then run `python src/verify_summary.py --summary path/to/draft.json`. This rejects stale fingerprints, invented metrics, altered values, incorrect units and unsupported numeric prose. It does not prove qualitative causal claims. No paid API calls are necessary.
